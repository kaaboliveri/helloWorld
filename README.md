# WorkoutApp - Votre Gestionnaire de Routine d'Entraînement Personnalisé

## Mission

WorkoutApp aide les personnes qui suivent une routine de musculation détaillée à gérer leurs séances plus efficacement et agréablement en offrant une application design avec un accès simplifié à leur programme et des chronomètres intégrés pour chaque exercice et temps de repos.

## Stack Technique (MVP V1.0)

*   **Framework Mobile :** React Native avec Expo
*   **Langage :** JavaScript (avec JSX)
*   **Navigation :** React Navigation
*   **Stockage Local (Routine) :** Données structurées (JSON/objets JS) intégrées dans l'application pour le MVP.
*   **IDE :** Visual Studio Code
*   **Gestion de Version :** Git

## Objectif du MVP V1.0

L'objectif de la première version est de fournir une application fonctionnelle et esthétique permettant à l'utilisateur de :

1.  Visualiser sa routine d'entraînement hebdomadaire via une vue calendaire.
2.  Consulter le détail de chaque séance (exercices, séries, répétitions, poids, notes).
3.  Suivre une séance avec un système de timers automatisés (30 secondes d'effort / 60 secondes de repos par série) avec vibrations.
4.  Marquer les exercices comme terminés et voir les exercices restants de la séance.

La routine d'entraînement sera initialement codée en dur dans l'application pour cette version.

## Plan de Développement (Résumé du Todo.md)

1.  **Fondations :** Setup du projet React Native (Expo), intégration des données de la routine.
2.  **UI de Base :** Écrans Calendrier et Détail de Séance.
3.  **Fonctionnalité Cœur :** Écran d'entraînement avec timers automatisés et gestion de la progression.
4.  **Finalisation MVP :** Application du design de base, persistance minimale de l'état et tests.
